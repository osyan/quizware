Self-host it in one command

QuizWare is a single Node.js container: no database, no build step, no external services. Run it on a school server, a VPS, a Raspberry Pi — or the laptop at the venue. 

docker run -d --name quizware -p 4000:4000 \
  --restart unless-stopped \
  ghcr.io/osyan/quizware:latest

Or build from source:

git clone https://github.com/osyan/quizware.git
cd quizware
docker compose up -d --build

Without Docker: npm ci --omit=dev && npm start (Node 18+), then open port 4000.

From USB buzzers to the browser

In 2006 the first USB quiz buzzer prototype was built for training sessions, a university astronomy quiz and church Bible quizzes. The projected "who buzzed first" display got such a reaction that it became a real product — for years it was the standard quiz buzzer in Hong Kong schools, with hundreds of units in service.

Phones changed the classroom, so QuizWare brings that same instant buzz to any device with a browser — free for schools, trainers and communities. No hardware to plug in, no dedicated server in the room.
